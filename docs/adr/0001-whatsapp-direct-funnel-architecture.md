# 0001: Conversão Direta via WhatsApp sem Gateway de Pagamento

Decidimos estruturar o site como um catálogo estático editorial de alto impacto em Next.js com conversão direta via links inteligentes de WhatsApp (`wa.me`) para cada serviço, em vez de implementar um e-commerce tradicional com carrinho e checkout de pagamento online. 

Consultoria de imagem de alto padrão e dress code corporativo requer alinhamento de agenda, personalização de escopo e relacionamento de confiança prévio; a automação de compra com checkout criaria atrito desnecessário e descaracterizaria a experiência de atendimento exclusivo.
